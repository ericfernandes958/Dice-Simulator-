# Dice-Simulator-
A python-based simulation investigating how the results of a rolling a fair six-sided dice change as the number of rolls increases. 

## What it does
Several simulations of rolling a fair six-sided dice with varying sample sizes occur. The simulation uses the following sample size:

- 10 rolls
- 100 rolls
- 1,000 rolls
- 10,000 rolls
- 100,000 rolls

For each sample size, the program calculates the frequency of each dice face and compares the actual results against the expected probability. The program then uses these two values to calculate the average percentage error for each sample size. 

## Visualisations 
The project displays the results using three graphs:

### Pie Chart 
Shows the percentage distribution for each dice face. This is different for every sample size and therefore you can switch between visualisations for each sample size using the labelled radio buttons.

### Grouped Bar Chart 
Compares the actual and expected data generated by each simulation. Similar to the pie chart, you can switch between every sample size to see a different graph using the radio buttons. 

### Line graph 
Shows how the average percentage error changes as the number of rolls increases. The graph uses a logarithmic x-axis to make comparisons simpler. 

## Requirements 
- Python 3.x
- Matplotlib
- NumPy

## Installation
Install the required dependencies using:

  pip install -r requirements.txt

## How to use?  
Run the program using:

    python main.py
